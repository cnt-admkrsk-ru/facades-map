# Внешний вид фасадов на центральных улицах Красноярска

Интерактивная карта, посвящённая 400-летию Красноярска. Проект показывает состояние фасадов зданий на центральных улицах (Карла Маркса, пр. Мира, Ленина) с возможностью просмотра фотографий, добавления новых меток и изменения их статуса.

## 🌟 Возможности

- **Интерактивная карта** с локальной подложкой исторического центра.
- **Просмотр карточек** зданий с фотографиями, координатами и описанием проблем.
- **Фильтрация** объектов по категориям (Проблемные, В ремонте, Удовлетворительные).
- **Список объектов**, сгруппированный по улицам (сворачиваемые аккордеоны).
- **Добавление новых меток** по координатам (клик правой кнопкой мыши по карте).
- **Загрузка фотографий** для любого здания.
- **Смена статуса** здания (с автоматической фиксацией даты изменения).
- **Облачное хранилище** (Supabase) для меток и фотографий — изменения видны всем пользователям.
- **Тёмная тема** (переключатель в шапке).
- **Адаптивный дизайн** для компьютеров и мобильных устройств.

## 🚀 Как запустить локально

1. Скачайте проект (или склонируйте репозиторий).
2. Откройте `index.html` в любом современном браузере (Chrome, Edge, Яндекс.Браузер).

> **Важно:** Для работы загрузки фото и синхронизации меток требуется интернет (доступ к Supabase).

## ☁️ Настройка облака Supabase

Если вы хотите использовать свой проект Supabase (вместо встроенного), выполните следующие шаги:

1. Зарегистрируйтесь на [supabase.com](https://supabase.com/) и создайте новый проект.
2. В разделе **Storage** создайте бакет с именем `photos` и сделайте его **публичным** (Public).
3. В разделе **SQL Editor** выполните следующий запрос для создания таблицы меток:

```sql
create table markers (
  id bigint generated by default as identity primary key,
  address text not null,
  number text,
  lat double precision not null,
  lng double precision not null,
  status text not null,
  photo text not null,
  problem text default '',
  updated text default '',
  created_at timestamp with time zone default timezone('utc'::text, now())
);

alter table markers enable row level security;

create policy "Allow public read" on markers for select using (true);
create policy "Allow public insert" on markers for insert with check (true);
create policy "Allow public update" on markers for update using (true);
create policy "Allow public delete" on markers for delete using (true);
```

4. В настройках проекта (**Project Settings → API**) скопируйте **Project URL** и **anon public** ключ.
5. Откройте `app.js` и замените значения в начале файла:

```
const SUPABASE_URL = 'https://ВАШ_ПРОЕКТ.supabase.co';
const SUPABASE_KEY = 'ВАШ_ANON_КЛЮЧ';
```

## 📸 Как добавить фото

1. Нажмите на метку здания на карте (или найдите его в списке).
2. В карточке здания нажмите **«Загрузить фото»**.
3. Выберите изображение на своём компьютере.
4. Фото автоматически загрузится в облако Supabase, и его увидят все пользователи.

## 💾 Как сохранить изменения (метки)

1. Добавьте новые метки или измените статусы зданий.
2. Нажмите кнопку **«Сохранить карту»**.
3. Данные отправятся в облако Supabase. После этого их увидят все пользователи при обновлении страницы.
